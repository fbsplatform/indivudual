# indivudual

Personal Claude Code mods.

## context-band

Shows context usage in the prompt footer (`Context 21%`, yellow from 60%, red from 80%).
Clicking it opens a menu above the prompt: compact, compact keeping the plan,
save to memory, save then compact.

### Install

At the prompt of a terminal session:

```
/plugin install context-band --marketplace fbsplatform/indivudual
```

From a shell:

```
claude plugin install context-band --marketplace fbsplatform/indivudual
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace
with `fbsplatform/indivudual`, then Add plugin.
